# 水镜先生 AI · Shuijing Neo-Celestial

融合东方传统历法命理（黄历、八字、紫微、灵签）与西洋占星（十二星座、缘分合盘、大阿卡纳塔罗）的轻量星象科技单页应用，内置上下文感知「水镜先生」AI 智能体。

## 核心功能

- **今日智能老黄历**：支持任意日期查询，实时计算干支纪年月日、农历、节气、建除十二神宜忌、冲煞、财喜神方位与十二时辰黄道吉凶。
- **八字排盘 & 紫微主星**：输入公历生辰与时辰，一键生成四柱八字、五行能量频谱、十天干日主解析与紫微十四主星速查。
- **十二星座今日星象**：每日自动更新综合/爱情/事业/财富四维评分、幸运色/数字与行动建议。
- **缘分合盘速配**：支持西洋星座相位合盘与东方生肖三合/六合测算。
- **灵签与每日塔罗**：水镜灵签摇签问卜 + 22 大阿卡纳塔罗正逆位抽牌。
- **水镜先生 AI 智能体**：
  - 实时感知当前页面排盘/星象/签文数据，一键深度白话解说。
  - 内置 3 款白胡子古装老者形象（水墨全息 / 3D 国漫 / 科幻插画）随心切换。
  - 默认本地推演引擎零配置可用，同时支持在设置面板接入 OpenAI / DeepSeek 兼容大模型 API。

## 本地运行

纯静态 HTML / CSS / JS，零依赖，直接用任意静态服务器或双击 `index.html` 即可打开：

```bash
python3 -m http.server 8090
```

打开浏览器访问 `http://localhost:8090`。
